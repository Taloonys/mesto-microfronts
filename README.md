## Слой композиции
* Использовал Webpack Module Federation, т.к.:
    * В исходном проекте использовался только React
    * Использовались некоторые формы, которые лучше было бы расшарить на несколько компонентов

> Поэтому нет смысла в использовании полной изоляции Single SPA

### Микрофронты

#### host
* `remotes` inject
* Добавление нового места, оставил тут, т.к. слишком минорный функционал

#### remotes
* auth
    * Логин
    * Регистрация
* profile
    * Просмотр и изменение профиля
    * Просмотр и изменения аватарки
* catalog
    * Каталог или view карточек (cards)
    * Взаимодействие с карточками

#### shared
* api
* PopupWithForm
* User context
